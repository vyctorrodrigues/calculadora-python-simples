# Calculadora Simples em Python

Uma aplicação de calculadora interativa via terminal (CLI) desenvolvida em Python, com tratamento de erros e histórico de operações.

## Funcionalidades

- Operações básicas: Adição, Subtração, Multiplicação e Divisão.
- Operações complementares: Potenciação, Radiciação e Porcentagem.
- Histórico da sessão atual.
- Tratamento robusto de erros (divisão por zero, entradas inválidas).

## Pré-requisitos

- Python 3.8 ou superior instalado.

## Como Executar

1. Clone ou baixe este repositório.
2. Navegue até o diretório do projeto:
   ```bash
   cd calculadora-python-simples
   ```
3. Execute o script principal:
   ```bash
   python main.py
   ```
